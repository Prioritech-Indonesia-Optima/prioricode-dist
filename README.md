# prioricode-dist

Serves `code.prioritech.co.id` via GitHub Pages: the PrioriCode installer scripts.

| Path          | Purpose                       |
| ------------- | ----------------------------- |
| `/install`    | macOS / Linux bash installer  |
| `/install.ps1`| Windows PowerShell installer  |

The source of truth for both scripts is the `install` and `install.ps1` files at the root of <https://github.com/Prioritech-Indonesia-Optima/prioricode>. Changes there must be copied here to deploy.
