# prioricode-dist

The live website for **code.prioritech.co.id** — PrioriCode's landing page,
docs, and installers. GitHub Pages serves the `main` branch from the repo root;
**pushing to `main` publishes the site** (1–3 min build + ≤10 min edge
staleness behind Cloudflare).

## What's here

| Path              | What it is                                                     |
| ----------------- | -------------------------------------------------------------- |
| `index.html`      | Product landing page (generated by `landing/`)                 |
| `landing/`        | React 19 + Vite single-file app that builds the landing page   |
| `docs/`           | Documentation site served at `/docs/` (generated by `docs-src/`) |
| `docs-src/`       | VitePress markdown source for the docs                         |
| `install`         | macOS / Linux bash installer — served at `/install`            |
| `install.ps1`     | Windows PowerShell installer — served at `/install.ps1`        |
| `brand/`          | Prioritech mark (SVG/PNG), favicon tile                        |
| `404.html`        | Branded not-found page                                         |
| `.nojekyll`       | Keeps Pages' Jekyll pass away from build outputs               |
| `AGENTS.md`       | Operating guide for agents/contributors — read it first        |

Sources live here; generated files (`index.html`, `docs/`) are committed and
must be rebuilt, never hand-edited. The `install`/`install.ps1` files are
mirrored byte-exact from the latest release tag of
[`Prioritech-Indonesia-Optima/prioricode`](https://github.com/Prioritech-Indonesia-Optima/prioricode)
(see `AGENTS.md` for the exact procedure — the drift CI expects this repo to
keep up).

## Local preview

```bash
cd landing  && bun install && bun run build   # rewrites ../index.html
cd docs-src && bun install && bun run build   # rewrites ../docs
cd .. && python3 -m http.server 8080          # serve the whole site
```
