On this page

Concept pages explain; these pages enumerate. Every flag, key, default, and name lives in exactly one table — linked from wherever it's mentioned. When a default changes, a single row changes.

  • CLI commands — Every command, subcommand, flag, and default of the prioricode binary.
    • Slash commands — Every /command in the TUI, with aliases and scope.
    • Keybindings — Every bindable id with its default chord; override syntax.
    • Config keys — prioricode.json and tui.json — every key, type, and default.
    • Environment variables — Every PRIORICODE_* switch and the third-party vars honored.
    • Agent tools — The tools the model can call — parameters, caps, gates.
    • Providers — Auth routes and env vars for known providers.

INFO

Tables describe the latest release of the tracked line (v0.1). Experimental entries carry an explicit marker; their existence is source-verified but their behavior may move between releases. See docs versioning.
