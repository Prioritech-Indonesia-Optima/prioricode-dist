PrioriCodeThe open source AI coding agent

Lives in your terminal, reads your codebase, runs your tools, and ships your code — one conversation at a time. Built by Prioritech in Jakarta.

Quickstart
Install
GitHub

Terminal-native

No IDE lock-in, no context switch. Run `prioricode` anywhere you already work — macOS, Linux, and Windows, x64 and ARM.

Model-agnostic

Anthropic, OpenAI, Google, local models — switch providers and models per session and bring your own keys.

Two agents, one Tab

Build mode has full access for development work; plan mode is read-only for analysis and code exploration. Switch with Tab.

TypeScript SDK

A fully typed client generated from the OpenAPI spec — embed the agent in your apps, scripts, and CI pipelines.

Cross-session coordination

Run several PrioriCode sessions on one project — presence, file claims, and message passing keep them from colliding.

Open source

The full agent, tools, and context engine are readable on GitHub. Audit it, fork it, ship it. Built in Jakarta, shipped daily.
